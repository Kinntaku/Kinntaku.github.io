# 编辑 hosts

编辑 `/etc/hosts` 文件 (注意是 hosts 不是 host)，添加以下内容：

```
0.0.0.0 paradise-s1.battleye.com
0.0.0.0 test-s1.battleye.com
0.0.0.0 paradiseenhanced-s1.battleye.com
```

# 下载 Proton BattlEye Runtime

进入 [steamdb页面](https://steamdb.info/app/1161040/info/)

点击右上角的 `Owned` 按钮, 跳转到 steam 客户端并安装

# 安装 

安装 `Grand Theft Auto V 增强版` 

右键库中游戏 - `属性` - `通用` - `启动选项` 填入以下内容:

```
PROTON_BATTLEYE_RUNTIME='~/.local/share/Steam/steamapps/common/Proton BattlEye Runtime' %command%
```
