# 锁屏相关

dwm 一般使用 i3lock 这里使用 i3lock-color, 为 i3lock 的增强版

创建锁屏脚本 `lock.sh`, 放到合适位置

```bash
#!/bin/sh

BLANK='#00000000'
CLEAR='#00000000'
DEFAULT='#ffffffff'
TEXT='#ffffffff'
WRONG='#fc5500ff'
VERIFYING='#0089B6ff'
BACKGROUND='#000000ff'

i3lock \
--color=$BACKGROUND          \
--insidever-color=$CLEAR     \
--ringver-color=$VERIFYING   \
\
--insidewrong-color=$CLEAR   \
--ringwrong-color=$WRONG     \
\
--inside-color=$BLANK        \
--ring-color=$DEFAULT        \
--line-color=$BLANK          \
--separator-color=$DEFAULT   \
\
--verif-color=$TEXT          \
--wrong-color=$TEXT          \
--time-color=$TEXT           \
--date-color=$TEXT           \
--layout-color=$TEXT         \
--keyhl-color=$VERIFYING         \
--bshl-color=$WRONG          \
--modifoutline-color=$TEXT  \
\
--screen 1                   \
--clock                      \
--indicator                  \
--time-str="%H:%M:%S"        \
--date-str="%A, %Y-%m-%d"       \
--keylayout 1                \
\
--time-size=100 \
--date-size=24 \
\
--radius 40                 \
--ring-width 10             \
--ind-pos="x+w/2:y+h/2+300" \
--time-pos="w/2:h/2-30"     \
--date-pos="w/2:h/2+30"     \
--verif-pos="w/2:h/2"       \
--wrong-pos="w/2:h/2"       \
--modif-pos="w/2:h-30"      \
```

参考 `https://github.com/Raymo111/i3lock-color/blob/master/examples/lock.sh`

# dwm

dwm 的设计理念为 suckless, 所有的自定义配置都需要修改头文件重新编译, 但是其具有极高的可拓展性, 可以通过应用 patch 进行扩展, 但是由于传统的手动应用 patch 需要解决过于复杂的合并工作, 以及需要遵守相当严格的合并顺序, 所以这里使用一个第三方的 dwm 改版: dwm-flexipatch, 这个版本将大部分常用补丁全部打入, 通过宏定义控制补丁的开启, 未开启的补丁在编译的时候会直接忽略以节省性能

## 克隆仓库

```bash
git clone https://github.com/bakkeby/dwm-flexipatch.git
```

克隆完成后请立即执行 `make`

此时会生成两个文件:

- config.h

- patches.h

这两个文件为对应 `.def.h` 模板文件的副本, 用于用户自定义修改配置, 以防干扰默认配置, 如果需要使用 git 管理自定义修改需要将这两个文件从 `.gitignore` 中移除

执行 `sudo make install` 安装

## 启动 dwm

这里以 greetd 为例

在 `$HOME` 中添加一个 `.xsession` 文件, 里面编写启动脚本

```bash
#设置qt主题
export QT_QPA_PLATFORMTHEME=qt6ct

#设置语言
export LANG=zh_CN.UTF-8 
export LC_ALL=zh_CN.UTF-8

# 合并 Xresources 配置, 见后文
xrdb -merge ~/.Xresources

# 设置壁纸
feh --bg-fill ".../wallpaper.png" &

# 禁用自动休眠/黑屏
xset -dpms && xset s off && xset s noblank

# 自动锁屏服务（注意：这里必须加 & 后台运行）
xss-lock --transfer-sleep-lock -- .../lock.sh -n &

# dwm 的 bar, 见后文
.../dwm_bar.sh &

picom -b & # 合成器, 见后文
dunst & # 通知管理器
fcitx5 & # 输入法
nm-applet & # 网络托盘
blueman-applet & # 蓝牙托盘
flclash & # 飞机
copyq & # 剪贴板
Snipaste & # 截图软件
lxqt-policykit-agent & # 应用授权后端
rog-control-center & # 华硕面板

exec dwm
```

修改 `/etc/greetd/config.toml` 中的 session 配置

```toml
command = "tuigreet --asterisks --time -r --cmd 'startx ~/.xsession'"
```

## `patches` 选择

编辑库中的 `patches.h` 文件中的宏定义, 标记为 1 开启 patch

- `BAR_AWESOMEBAR_PATCH`: 类似 `awesomewm` 的任务栏, 显示当前虚拟桌面的所有窗口标题, 点击即可隐藏标签

- `BAR_STATUS_PATCH`: 允许在状态栏中使用颜色和特殊格式

- `BAR_STATUS2D_PATCH`: 许在状态栏中使用十六进制真彩色

- `BAR_SYSTRAY_PATCH`: 启用系统托盘

- `BAR_TAGS_PATCH`: 虚拟桌面指示器

- `BAR_WINTITLE_PATCH`: 显示窗口标题, 是 `BAR_AWESOMEBAR_PATCH` 的依赖

- `ALWAYSCENTER_PATCH`: 允许设置浮动窗口出现的位置

- `CFACTS_PATCH`: 允许调整单独平铺窗口大小

- `DRAGCFACT_PATCH`: 允许通过按键拖拽调整平铺窗口高度

- `DRAGMFACT_PATCH`: 允许通过按键拖拽调整平铺窗口宽度

- `FLOATPOS_PATCH`: 允许设置浮动窗口创建时位置以及大小

- `FOCUSONCLICK_PATCH`: 关闭鼠标哪窗口焦点就到哪

- `SELFRESTART_PATCH`: 允许热重载

- `SHIFTVIEW_CLIENTS_PATCH`: 可以前后切换虚拟桌面并且切换时候自动跳过空白虚拟桌面, 这里用于切换窗口

- `FOCUSADJACENTTAG_PATCH`: 前后切换虚拟桌面但是不跳过空白虚拟桌面, 这里用于移动窗口到其他虚拟桌面

- `VANITYGAPS_PATCH`: 设置窗口间隔

- `XRDB_PATCH`: 允许读取 `.Xresources` 文件的颜色配置

- `TILE_LAYOUT`: 默认的布局模式, 还有很多模式可以参考

- `FULLSCREEN_PATCH` 允许设置全屏

# 电源脚本编写, 使用rofi

```bash
MENU="rofi -dmenu -p Power"

options="Suspend\nSleep\nRestart\nShutdown\nExit"

chosen=$(echo -e "$options" | $MENU)

case "$chosen" in
    Suspend)
        systemctl suspend
        ;;
    Sleep)
        systemctl hibernate
        ;;
    Restart)
        reboot
        ;;
    Shutdown)
        poweroff
        ;;
    Exit)
        pkill dwm
        ;;
    *)
        exit 0
        ;;
esac
```

# 状态栏脚本编写

编写 `dwm_bar.sh` 放到合适位置

```bash
#!/bin/bash

CLR_CPU="^c#BF616A^"     # 红
CLR_MEM="^c#D08770^"     # 橙
CLR_VOL="^c#A3BE8C^"     # 绿
CLR_MIC="^c#88C0D0^"     # 青
CLR_PWR="^c#81A1C1^"     # 蓝
CLR_BAT="^c#B48EAD^"     # 紫
CLR_DATE="^c#ECEFF4^"    # 白
CLR_WARN="^c#ECEFF4^^b#BF616A^" # 警告
RESET="^d^"


update_status() {
    # --- CPU 使用率 ---
    CPU_VAL=$(grep 'cpu ' /proc/stat | awk '{usage=($2+$4)*100/($2+$4+$5)} END {printf("%.0f", usage)}')
    CPU_DIS="${CLR_CPU}CPU:${CPU_VAL:-0}%${RESET}"

    # --- 内存使用率 ---
    MEM_TOTAL=$(awk '/MemTotal/ {print $2}' /proc/meminfo)
    MEM_AVAIL=$(awk '/MemAvailable/ {print $2}' /proc/meminfo)
    MEM_VAL=$(( (MEM_TOTAL - MEM_AVAIL) * 100 / MEM_TOTAL ))
    MEM_DIS="${CLR_MEM}MEM:${MEM_VAL}%${RESET}"

    # --- 扬声器音量 ---
    V_NUM=$(pactl get-sink-volume @DEFAULT_SINK@ 2>/dev/null | grep -Po '\d+(?=%)' | head -n 1 || echo "0")
    if pactl get-sink-mute @DEFAULT_SINK@ 2>/dev/null | grep -q "yes"; then
        VOL_DIS="${CLR_WARN}VOL:M${RESET}"
    else
        VOL_DIS="${CLR_VOL}VOL:${V_NUM}%${RESET}"
    fi

    # --- 麦克风音量 ---
    M_NUM=$(pactl get-source-volume @DEFAULT_SOURCE@ 2>/dev/null | grep -Po '\d+(?=%)' | head -n 1 || echo "0")
    if pactl get-source-mute @DEFAULT_SOURCE@ 2>/dev/null | grep -q "yes"; then
        MIC_DIS="${CLR_WARN}MIC:M${RESET}"
    else
        MIC_DIS="${CLR_MIC}MIC:${M_NUM}%${RESET}"
    fi

    # --- 电源模式 (Power-Profiles-Daemon) ---
    PWR_MODE=$(powerprofilesctl get 2>/dev/null || echo "N/A")
    case "$PWR_MODE" in
        *performance*) PWR_STR="PERF" ;;
        *balanced*)    PWR_STR="BAL"  ;;
        *power-saver*) PWR_STR="SAVE" ;;
        *)             PWR_STR="N/A"  ;;
    esac
    PWR_DIS="${CLR_PWR}PWR:${PWR_STR}${RESET}"

    # --- 亮度 ---
    BRIGHT_VAL=$(brightnessctl g 2>/dev/null | awk '{print int($1/255*100)}' || echo "0")
    BRT_DIS="${CLR_BRT}BRT:${BRIGHT_VAL}%${RESET}"

    # --- 电池 ---
    BAT_PATH=$(ls /sys/class/power_supply/BAT* -d 2>/dev/null | head -n 1)
    if [ -n "$BAT_PATH" ]; then
        BAT_VAL=$(cat "$BAT_PATH/capacity" 2>/dev/null || echo "0")
        [ "$BAT_VAL" -lt 20 ] && BAT_DIS="${CLR_WARN}BAT:${BAT_VAL}%${RESET}" || BAT_DIS="${CLR_BAT}BAT:${BAT_VAL}%${RESET}"
    else
        BAT_DIS=""
    fi
    
    # --- 时间 ---
    DATE_VAL=$(date +"%m.%d %H:%M")
    DATE_DIS="${CLR_DATE}${DATE_VAL}${RESET}"

    STATUS=" ${CPU_DIS} ${MEM_DIS} ${VOL_DIS} ${MIC_DIS} ${PWR_DIS} ${BRT_DIS} ${BAT_DIS}  ${DATE_DIS} "
    
    xprop -root -f WM_NAME 8s -set WM_NAME "$STATUS"
}

(
    while true; do
        update_status
        sleep 2
    done
) &

(
    pactl subscribe 2>/dev/null | grep --line-buffered -E "sink|source" | while read -r _; do
        update_status
    done
) &

update_status
while true; do sleep 60; done
```
