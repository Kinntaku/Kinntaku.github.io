## Hyprland 实现最小化的哲学

特殊工作区是 Hyprland 上的一个叠加层, 会叠加在当前工作区上方

最小化本质上是把需要最小化的临时窗口在特殊工作区打开

但是会出现问题, 比如我在特殊工作区的临时任务管理器中打开一个文档, 那么这个文档显然不属于临时窗口, 所以需要把这个文档移动回原来的工作区

安装软件

```bash
sudo pacman -S socat
```

创建脚本写入

```bash
#!/bin/bash

HIS=$HYPRLAND_INSTANCE_SIGNATURE
SOCKET_PATH="$XDG_RUNTIME_DIR/hypr/$HIS/.socket2.sock"

# 监听事件流
socat -U - UNIX-CONNECT:"$SOCKET_PATH" | while read -r line; do
    
    # 处理新打开的平铺窗口 (直接捕获 openwindow)
    if [[ "$line" == openwindow* ]]; then
        ADDR="0x${line#*>>}"
        ADDR="${ADDR%%,*}"
        
        WS_NAME=$(hyprctl clients -j | jq -r ".[] | select(.address == \"$ADDR\") | .workspace.name" 2>/dev/null)
        IS_FLOATING=$(hyprctl clients -j | jq -r ".[] | select(.address == \"$ADDR\") | .floating" 2>/dev/null)

        if [[ "$WS_NAME" == special:* && "$IS_FLOATING" == "false" ]]; then
            hyprctl dispatch movetoworkspace e+0,address:$ADDR
            hyprctl dispatch togglespecialworkspace
            hyprctl dispatch focuswindow address:$ADDR
        fi
    fi

    # 处理从悬浮转为平铺, 或延迟确定的平铺状态
    if [[ "$line" == changefloatingmode* ]]; then
        # 格式: changefloatingmode>>ADDR,FLOATING_STATE
        DATA="${line#*>>}"
        ADDR="0x${DATA%%,*}"
        STATE="${DATA#*,}"

        # 如果 STATE 为 0, 说明现在是平铺状态
        if [ "$STATE" == "0" ]; then
            WS_NAME=$(hyprctl clients -j | jq -r ".[] | select(.address == \"$ADDR\") | .workspace.name")
            if [[ "$WS_NAME" == special:* ]]; then
                hyprctl dispatch movetoworkspace e+0,address:$ADDR
                hyprctl dispatch togglespecialworkspace
                hyprctl dispatch focuswindow address:$ADDR
            fi
        fi
    fi
done
```

## dotfiles 管理

创建文件夹

创建目录

- home: ~ 目录下的文件, 如 .zshrc

- config: ~/.config 目录下按文件夹分类的文件

- scripts: 存储自定义脚本

- shotcut_scripts: 存储快捷启动脚本

创建链接脚本

功能列表

- 将 home 目录下的文件创建符号链接到用户主目录

- 将 config 目录下的文件夹创建符号链接到 ~/.config 目录

```bash
#!/bin/bash

# 获取脚本所在目录的绝对路径
DOTFILES_DIR=$(cd "$(dirname "$0")"; pwd)
CONFIG_DIR="$HOME/.config"

# 确保 .config 目录存在
mkdir -p "$CONFIG_DIR"

# 定义执行软链接的函数
link_file() {
    local src=$1
    local dest=$2

    # 如果目标已存在且是普通文件 (不是软链接)  , 先备份
    if [ -f "$dest" ] && [ ! -L "$dest" ]; then
        echo "备份原文件: $dest -> $dest.bak"
        mv "$dest" "$dest.bak"
    fi

    # 创建软链接 (-s: soft, -f: force, -n: treat link name as normal file)
    ln -sfn "$src" "$dest"
    echo "已链接: $dest -> $src"
}

echo "--- 开始部署 Dotfiles ---"

# 1. 处理 home 目录下的文件 (如 .zshrc)
# 遍历 home 文件夹下所有以 . 开头的文件
for file in "$DOTFILES_DIR/home"/.*; do
    # 排除 . 和 .. 目录
    basename=$(basename "$file")
    if [ "$basename" != "." ] && [ "$basename" != ".." ]; then
        link_file "$file" "$HOME/$basename"
    fi
done

# 2. 处理 config 目录下的文件夹 (如 nvim, fzf)
for dir in "$DOTFILES_DIR/config"/*; do
    if [ -d "$dir" ]; then
        basename=$(basename "$dir")
        link_file "$dir" "$CONFIG_DIR/$basename"
    fi
done

echo "--- 部署完成！ ---"
```

- 给 shotcut_scripts 目录下的脚本生成桌面快捷方式

```bash
#!/bin/bash

# 获取项目根目录的绝对路径
DOTFILES_DIR=$(cd "$(dirname "$0")"; pwd)
DESKTOP_DIR="$HOME/.local/share/applications"

# 确保桌面快捷方式目录存在
mkdir -p "$DESKTOP_DIR"

echo "--- 开始为 shotcut_scripts 目录下的脚本生成桌面快捷方式 ---"

for script in "$DOTFILES_DIR/shotcut_scripts"/*.sh; do
    # 获取文件名和不带后缀的名称
    filename=$(basename "$script")
    name="${filename%.*}"

    desktop_file="$DESKTOP_DIR/$name.desktop"

    # 创建 .desktop 文件
    cat > "$desktop_file" <<EOF
[Desktop Entry]
Version=1.0
Type=Application
Name=$name
Comment=Launch $name script
Exec=$script
Icon=utilities-terminal
Terminal=false
Categories=Script;Utility;
EOF

    # 赋予执行权限
    chmod +x "$desktop_file"
    echo "已生成: $desktop_file"
done
echo "快捷方式已存放到: $DESKTOP_DIR"
```
